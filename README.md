Emission-factors.com provides a free REST API and MCP server that translates US ZIP codes into EPA eGRID grid‑carbon emission factors, electricity rates, hourly grid carbon data, utility tariffs, and plant emissions. It aggregates data from EPA eGRID, EIA‑930, EPA CAMD, and OpenEI URDB, offering 12 data endpoints for developers and sustainability teams to calculate Scope 2 emissions without requiring an API key or signup. The service includes tools for bulk CSV processing, hourly intensity calculations, and AI‑ready MCP tools, supporting CDP, CSRD, and SB 253 compliance.
